How it works

About this system

Recommendation engine

The app combines movie titles, genres, user tags, rating averages, rating counts, and TF-IDF cosine similarity to rank related movies.

Why Flask

Flask gives this project a normal website structure: routes, templates, static styling, CSV downloads, and room for login or database features later.

Project files

app.py is the Flask web server. movie_complete.py is the recommendation engine. The templates and static folders control the frontend.
